
# Architecture Documentation

This directory contains the architecture documentation for the Enterprise AWS Cloud Infrastructure project.

## Purpose

Document the AWS infrastructure design, network layout, traffic flow, and relationships between cloud services.

## Planned Documentation

- AWS architecture diagram
- VPC and subnet layout across two Availability Zones
- Public and private network tiers
- Internet Gateway and NAT Gateway traffic flow
- Application Load Balancer to EC2 traffic flow
- Application and database connectivity

## Project Status

The architecture documentation is being developed alongside the infrastructure implementation.

Only verified resources and tested traffic flows will be represented as completed.
